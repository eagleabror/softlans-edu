# Codex instructions for SoftLans Edu 2.0

Before implementing, reviewing, or modifying any frontend, dashboard, component,
navigation, table, form, styling, UI/UX, accessibility, or responsive design work,
read and apply [.agents/skills/softlans-ui-design/SKILL.md](.agents/skills/softlans-ui-design/SKILL.md).
Apply it even when the task does not explicitly name the skill. Read any applicable
instructions nearer the files being changed as well.

Preserve working design and Uzbek interface copy. Keep changes scoped to the
requested UI; a design task alone does not authorize a full application redesign,
CRM behavior changes, API/contract changes, or database model changes. Reuse the
existing React components, shared CSS, and Tailwind v4 theme before adding new
patterns. Run the checks relevant to the changed files and report their results.

Explicit invocation example:

> Use $softlans-ui-design to improve the students table on mobile while preserving
> its filters, pagination, permissions, and existing CRM behavior.

If the skill is not listed in the session, open
`.agents/skills/softlans-ui-design/SKILL.md` directly and follow it.
